MOUNT EXPORTS — STATIC GITHUB PAGES PACKAGE

Files:
- index.html: website page
- styles.css: responsive design
- script.js: hero slider, product filters/details, mobile menu, FAQ/form interactions
- icon.svg: site icon

Deploy:
1. Extract this ZIP.
2. Upload the contents (not the containing folder) to the root of a GitHub repository.
3. In GitHub, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.

Notes:
- This is a static HTML/CSS/JavaScript site. It requires no Node.js or build step.
- Photography uses the Pexels image URLs referenced in the supplied project, so internet access is required to load those photographs.
- GitHub Pages cannot run the original Next.js API routes/database. The enquiry form opens WhatsApp with the submitted details; submissions are not stored in a database.
